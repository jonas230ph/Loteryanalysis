# Call Center Workforce SLA Prototype — Design

## Goal

Provide a testable Power Platform prototype for workforce supervisors to monitor monthly service-level agreement (SLA) and abandonment rate (ACR) by Voice and Chat, record recovery actions, and automatically alert managers when performance misses its target.

## Scope

- Import sample daily channel-performance data into a SharePoint/Microsoft List named `Channel Performance`.
- Build a Power BI report with monthly KPI cards, channel comparisons, target variance, trends, and a list of threshold breaches.
- Embed a Power Apps canvas form in the report so a supervisor can record an exception and recovery action for the selected channel/date.
- Store actions in a `SLA Recovery Actions` SharePoint/Microsoft List.
- Run a Power Automate flow on new action records. It notifies the assigned manager via Teams or email and marks the alert as sent.
- Include a second scheduled flow design that scans for daily breaches and creates/alerts on an exception when SLA or ACR is outside its target.

## Data Model

### Channel Performance

One row per Date x Channel. Fields: `PerformanceDate`, `MonthStart`, `Channel`, `OfferedContacts`, `AnsweredWithinTarget`, `AbandonedContacts`, `SLA_TargetPct`, `ACR_TargetPct`, `Supervisor`, and `ManagerEmail`.

Metrics are calculated from contact counts, not averaged percentages:

- SLA % = AnsweredWithinTarget / OfferedContacts
- ACR % = AbandonedContacts / OfferedContacts

### SLA Recovery Actions

One row per supervisor-entered action. Fields: `ActionID`, `PerformanceDate`, `Channel`, `SLA_Pct`, `ACR_Pct`, `BreachType`, `RootCause`, `RecoveryAction`, `Owner`, `DueDate`, `Status`, `ManagerEmail`, `AlertSent`, and `AlertSentAt`.

`ActionID` is generated by Power Apps with `GUID()`; `AlertSent` begins as `No`.

## Power BI Report

The report has one Operations Overview page:

- Slicers: month, channel, supervisor.
- KPI cards: SLA %, SLA target, ACR %, ACR target, and breached days.
- Clustered column chart: SLA % versus target by channel.
- Clustered column chart: ACR % versus target by channel.
- Line chart: daily SLA % and ACR % by selected channel.
- Exception table: breached records, ownership, recovery status, and alert state.
- Embedded Power Apps visual for submitting a selected performance exception.

Default targets are Voice SLA 80% / ACR 5% and Chat SLA 85% / ACR 4%; the sample dataset includes both normal and breached days.

## Automation

### Action notification flow

Trigger: a new `SLA Recovery Actions` list item is created with `AlertSent = No`.

The flow sends a Teams adaptive-card/email alert to `ManagerEmail` summarizing the channel, date, missed KPI, action owner, and due date. It then updates the list item to `AlertSent = Yes` and stores `AlertSentAt`.

### Daily threshold-monitoring flow

Trigger: daily scheduled recurrence. It finds performance rows where SLA is below target or ACR is above target, creates a recovery action if one does not already exist for that date/channel/breach type, and sends the same manager notification.

## Error Handling and Test Criteria

- Reject app submission when required action, owner, manager email, or due date is missing.
- Prevent duplicate automated actions for the same date, channel, and breach type.
- Treat zero offered contacts as blank rather than a 0% KPI.
- Verify report measures against hand-calculated sample rows.
- Confirm a manual Power Apps submission creates one list record and a single manager alert.
- Confirm a scheduled breach run creates alerts only for newly discovered breaches.

## Deliverables

- Import-ready sample CSV files.
- A Power BI build guide with Power Query, DAX, visuals, and publishing steps.
- A Power Apps canvas-form configuration guide.
- Two Power Automate flow build guides and test checklist.
